# M1a Sim Core and Connectivity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the pure sim core for M1: address and interface-name helpers, device classes and models, `NetworkSim` with cabling, an L2 resolver, and `NetworkSim.ping` with precise fail reasons (plan tasks 1.1 to 1.8).

**Architecture:** Everything lives under `res://sim/` as `RefCounted` classes with static typing. Device state is plain data; `NetworkSim` owns the device registry, the cables and the spare-cable count, and is the only thing that emits signals (on `SimEvents`). `L2` and `Resolver` are stateless static classes that read a `NetworkSim`; `NetworkSim.ping` delegates to `Resolver`.

**Tech Stack:** Godot 4.7.2, GDScript, GdUnit4 v6.2.2, bash purity check.

**Spec:** `docs/SPEC.md` §3.3, §3.4, §4, §6; `docs/IMPLEMENTATION_PLAN.md` M1a (tasks 1.1 to 1.8); `.claude/skills/netsec-sim/SKILL.md`.

## Global Constraints

- Sim classes extend `RefCounted` (or `Resource`), never `Node`. No `get_tree`, `Input`, `Time`, `OS.get_ticks_*`, `Timer`, `await`, `randf`/`randi`, `shuffle`/`pick_random`, autoloads, or `res://world|ui|game/` paths under `sim/`. `tools/check_sim_purity.sh` enforces it.
- Static typing on every var, param and return. `class_name` on every reusable script. snake_case files, PascalCase classes. Enums, never string literals, for modes and fail reasons. Signals are past tense.
- Interface names are stored canonical (`GigabitEthernet0/1`). Ports are `"<device_id>:<CanonicalName>"`, e.g. `"S1:FastEthernet0/1"`. Normalize all input through `IfName`.
- Test files mirror `sim/` under `res://tests/` (e.g. `sim/net/ipv4.gd` -> `tests/net/test_ipv4.gd`), extend `GdUnitTestSuite`, and carry a `class_name`. Table-driven cases use GdUnit4 `test_parameters := [[...], ...]`.
- Defaults (SPEC §4): router interfaces start shut; switch ports start up, access, VLAN 1; host/server NICs start up; a new subinterface starts `admin_up`; VLAN 1 always exists.
- Physical interface oper-up = both ends `admin_up` and a cable. Subinterface oper-up = parent oper-up and itself `admin_up`.
- Line endings LF. No `.tscn` work in this plan.
- **Verify gate (run at the end of every task):** `tools/test_check_sim_purity.sh && tools/check_sim_purity.sh && GODOT_BIN=~/Downloads/Godot_v4.7.2-stable_linux.x86_64 addons/gdUnit4/runtest.sh -a res://tests`. ## Resolver semantics this plan pins (written into SPEC §6 by Task 0)

1. **Order per hop:** `NO_IP` -> sender's own egress L1 (`NO_LINK` if no cable, `ADMIN_DOWN` if cabled but not oper-up) -> next-hop decision (`WRONG_SUBNET` / `NO_GATEWAY` / `NO_ROUTE`) -> owner lookup (`HOST_UNREACHABLE`) -> L2 to the owner in three tiers: cable graph (`NO_LINK`), oper-up graph (`ADMIN_DOWN`), VLAN-aware graph (`VLAN_MISMATCH`).
2. **`hops`** lists L3 devices only: the source, each router traversed, and the device that owns the destination IP as the last entry. Switches never appear. (This is what `to_device` and `via` objectives read.)
3. **`fail_at`** is the id of the device holding the packet when it failed (the sender for L1/L2 failures; a non-forwarding host that received it for `HOST_UNREACHABLE`). `""` when there is no device (unknown source).
4. **Reply path:** after the forward path succeeds, the destination runs the same walk toward the original source IP. A reply failure returns `success = false` with the reply's reason and `fail_at`; `hops` stays the forward path. A router source uses the IP of its egress interface as source address.
5. **Switch VLAN rules:** a switch drops frames in a VLAN missing from its `vlans`, on ingress or egress. An access port accepts only untagged frames. A trunk accepts tagged frames in its allowed list and treats untagged frames as VLAN 1 (native), which must also be allowed; VLAN 1 leaves a trunk untagged, other VLANs leave tagged. Host NICs and router physical ports accept only untagged frames; a router subinterface accepts frames tagged with its `dot1q_vlan` on its parent.
6. **Connected routes** exist for any interface with a valid address regardless of oper state (L1/L2 tiers then report `ADMIN_DOWN` etc.). Routes are chosen by longest prefix over connected + static. A static route's next hop must lie inside a connected subnet, else `NO_ROUTE`.
7. **Ownership:** an interface owns an IP if `has_address()` and the parsed addresses are equal, regardless of oper state. With duplicate owners, pick the first owner reachable in the VLAN-aware graph, scanning devices in sorted id order; if none is reachable, classify against the first owner in sorted id order.
8. **Edge inputs:** unknown source id, or a switch as source -> `NO_IP`, `fail_at ""`. Destination that is empty, malformed or `0.0.0.0` -> `HOST_UNREACHABLE`, `fail_at` = source. A next hop owned by the sender itself -> `HOST_UNREACHABLE`. A subinterface with `dot1q_vlan <= 0` is never reachable and cannot send: `VLAN_MISMATCH`. Hosts do not forward: a gateway owned by a host -> `HOST_UNREACHABLE` at that host. More than 32 L3 hops -> `NO_ROUTE` at the device where the limit hit.

## Review Focus

Failure modes the spec implies but no obvious task exercises (each has an owning test below):

1. **L2 loops with no STP** (switch ring, router default-route ping-pong) must terminate, not hang. Owned by Task 7 (`test_ring_terminates`) and Task 8 (`test_route_loop_terminates_no_route`).
2. **Bad address strings** (`""`, `"256.1.1.1"`, `"0.0.0.0"`, leading zeros) must give a clean failure, never a crash. Owned by Task 1 (parse) and Task 8 (`test_bad_destination_strings`).
3. **Self-targeting** (ping own IP, gateway set to own IP). Owned by Task 8 (`test_ping_own_ip`, `test_gateway_is_self`).
4. **Duplicate IPs** must resolve deterministically. Owned by Task 8 (`test_duplicate_ip_*`).
5. **VLAN missing from the switch database, and subinterface with no `dot1q_vlan`** must not forward (the M1 mission teaches creating VLANs and tagging). Owned by Task 7 (`test_vlan_missing_from_db_blocks`) and Task 8 (`test_sub_without_dot1q`).

### Task 8 (plan 1.8): `Resolver` and `NetworkSim.ping`

**Files:**
- Create: `sim/net/resolver.gd`
- Modify: `sim/core/network_sim.gd` (add `ping`)
- Test: `tests/net/test_resolver.gd`

**Interfaces:**
- Consumes: `L2` (Task 7), `PingResult` (Task 6), `IPv4`, `NetworkSim` internals, pinned semantics 1 to 8.
- Produces: `class Resolver extends RefCounted`, `static ping(net: NetworkSim, src_id: String, dst_ip: String) -> PingResult`; `NetworkSim.ping(src_id: String, dst_ip: String) -> PingResult` delegating to it.

Algorithm the signature does not determine:
1. `_walk(net, start_device, dst_addr) -> {ok, reason, at, hops, arrived_at, src_ip}` carries the packet from `start_device` toward `dst_addr` and returns the L3 hop list; `ping` calls it once forward and, on success, once more from the destination device toward the forward source IP.
2. At the current device: if it owns `dst_addr` -> arrived. Host: egress = its NIC; router: egress interface and next hop from the longest-prefix match (a connected match delivers directly, a static match delivers to its next hop); a router start uses the egress interface IP as source address.
3. Deliver to next-hop IP over the egress interface: owner lookup, then egress L1 check, then tiers CABLES -> `NO_LINK`, OPER -> `ADMIN_DOWN`, VLAN -> `VLAN_MISMATCH` using `L2.reaches` with start tag 0 (or the subinterface's `dot1q_vlan`).
4. On arrival at a non-owner: a router continues the loop; anything else fails `HOST_UNREACHABLE` at that device. Stop with `NO_ROUTE` after 32 L3 hops.
